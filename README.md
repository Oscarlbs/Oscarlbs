## Hi, I'm Óscar

Backend and data engineer from Vigo, Spain. Most of what I build is in Python: APIs, data pipelines and automation.

I work at Cuatro Digital Technologies on backend services and geospatial systems, like wildfire prediction and flight route planning, using Airflow, NiFi, Kafka and PostGIS. I also take on freelance data projects, mostly dashboards and reporting for clients in aviation, healthcare and banking.

I studied web (DAW) and multiplatform (DAM) application development. I speak Spanish and English, and I'm open to remote work.

### Side projects

- **[Pedrafonte](https://github.com/Oscarlbs/pedrafonte)**: a 3D medieval village where the villagers are run by an LLM. The model only suggests what they say and do, and the game engine checks it before anything changes. TypeScript, Three.js, FastAPI, PostgreSQL.
- **[crypto-trend-bot](https://github.com/Oscarlbs/crypto-trend-bot)**: a daily trend-following bot for BTC and ETH, with backtests, a kill switch and a small macOS app to keep an eye on it. Python, pandas, Docker.
- **[UNO Gym](https://github.com/Oscarlbs/JUEGO-UNO)**: a small React Native app for deciding who does the next set at the gym.
- **[Portfolio](https://github.com/Oscarlbs/oscar-lopez-portfolio)**: my personal site, made with Next.js.
