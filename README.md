### 👨‍💻 About me

- 🔭 At **Cuatro Digital Technologies** I build backend services, automation pipelines and geospatial systems, from **wildfire prediction** to **flight-route planning**, with Python, Airflow, NiFi, Kafka and PostGIS.
- 📊 As a freelancer I do **data & analytics engineering** for international clients in aviation, healthcare and banking: dashboards, reporting platforms and web apps.
- 🤖 I work **AI-native**: Claude Code and LLM agents are part of how I design, build and test software.
- 🎓 I hold two higher vocational degrees in software development: Web Applications (DAW) and Multiplatform Applications (DAM).
- 🌍 I speak English and Spanish fluently and I'm **open to remote work**.
